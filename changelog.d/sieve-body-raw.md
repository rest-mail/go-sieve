Changed (breaking): `body :raw` (RFC 5173 §5.1) now matches the undecoded body instead of the extracted text. `Message.RawBody` holds everything after the header's empty line as it is on the wire, so transfer encodings, multipart boundaries and nested MIME headers can be matched, and `RawBodySet` says the host supplied it; `:text` and `:content` do not read it. A Message without `RawBodySet` makes `body :raw` a runtime error, `ErrRawBodyUnavailable`, with the fail-safe implicit keep, because the RFC forbids decoding for `:raw`. Hosts that run `:raw` scripts must set `RawBody` and `RawBodySet`. Closes #90.
