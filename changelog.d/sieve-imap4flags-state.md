Added: imap4flags flag state (RFC 5232, #89). The evaluator holds the internal flag variable for each evaluation and implements the `hasflag` test (`:is` and `i;ascii-casemap` by default, `:count` counting distinct flags). A host that also implements the optional `FlagDeliverer` interface (`KeepWithFlags`, `FileIntoWithFlags`) receives every `keep` and `fileinto` with its effective flags, the `:flags` list when given and otherwise the internal variable when the action ran, instead of `Keep` and `FileInto`; merged duplicate deliveries keep the last flag list, so these calls come once per destination after the script finishes. `Outcome.ImplicitKeepFlags` carries the implicit keep's flags. `Flag` is still called for each flag action, and an Executor without the interface behaves as before. Closes #89.
