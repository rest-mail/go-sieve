Added: With `variables`, a `:comparator` name may be built from a variable (RFC 5229 §3). It is expanded when its test runs and checked as `Parse` checks a constant one: built in or declared with `require`, and able to serve the match type. A bad value is a runtime error with the fail-safe keep; a constant bad name is still refused by `Parse`. The relational operator of `:value` and `:count` already worked this way. Closes #100.
