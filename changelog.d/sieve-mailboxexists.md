Added: The `mailboxexists` test (RFC 5490 §3.1), through `MailboxChecker`, an optional Executor interface. `MailboxExists(name string) (bool, error)` answers for the script's user whether the mailbox exists and accepts delivery; the test is true only if every named mailbox does, and with `variables` the names are expanded when the test runs. A lookup error is a runtime error with the fail-safe keep, never a missing mailbox; an Executor without the interface fails the same way with `ErrMailboxQueryUnavailable`. Closes #91.
