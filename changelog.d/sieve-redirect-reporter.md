Added: `RedirectReporter`, an optional Executor interface whose `TryRedirect(addr, copy) error` replaces `Redirect`: nil is a forwarded redirect, `ErrRedirectSkipped` (or an error wrapping it) a redirect host policy silently skipped, which no longer cancels the implicit keep (RFC 5228 §4.2) and counts as no delivery, and any other error a runtime failure with the fail-safe implicit keep. An Executor without the interface behaves as before. Closes #93.
